# Full Stack Projects

## Project Overview

This section contains complete full-stack web application projects that integrate HTML/CSS, PHP, and MySQL. Each project demonstrates real-world development practices and SQA assessment requirements.

## Project 1: Student Registration System

### Features
- User registration with form validation
- Student profile management
- Database storage of student information
- Session-based authentication
- Role-based access control (Admin/Student)

### Technologies
- Frontend: HTML, CSS (responsive design)
- Backend: PHP
- Database: MySQL

### Files
- `01_student_registration/` - Complete project directory
- `index.html` - Landing page
- `register.html` - Registration form
- `login.php` - Authentication logic
- `dashboard.php` - Student dashboard
- `database.sql` - Database schema
- `config.php` - Database configuration

### Learning Outcomes
- Form creation and validation
- PHP server-side processing
- Database design and implementation
- Session management
- Security best practices

## Getting Started

1. Choose a project from above
2. Review the database schema (database.sql)
3. Set up the database in your MySQL server
4. Configure the database connection (config.php)
5. Deploy files to your web server
6. Follow the implementation guide in each project folder

## Development Requirements

- Local web server (Apache, Nginx)
- MySQL Server
- PHP 7.4+
- Text editor or IDE
- Browser for testing

## Assessment Criteria

- Correct implementation of all features
- Proper form validation
- Secure database operations
- User authentication and authorization
- Responsive design implementation
- Code organization and documentation
- Security best practices
- Performance optimization
