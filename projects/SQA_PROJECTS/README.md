# Advanced Higher Computing Science Project Resources

This page contains links to current official material and optional project practice ideas. The ideas below are not SQA-issued project choices or assessment requirements.

## Official References

- [Advanced Higher Computing Science course specification, edition 5.0](https://www.sqa.org.uk/sqa/files_ccc/ah-course-spec-computing-science.pdf), valid from session 2026-27.
- [Advanced Higher Computing Science project assessment task, version 4.0](https://www.sqa.org.uk/sqa/files_ccc/ah-cat-computing-science.pdf), valid from session 2026-27.
- [SQA AH Computing Science Project Workbook](https://www.sqa.org.uk/sqa/files_ccc/AH-computing-science-project-workbook-2.pdf). Check the current task for the correct templates and evidence requirements.

The course specification permits projects integrating software design and development (SDD), database design and development (DDD), and web design and development (WDD):

- SDD using object-oriented programming, integrated with DDD.
- SDD using procedural programming, integrated with DDD.
- DDD integrated with SDD or WDD.
- WDD integrated with DDD.

The current assessment task provides specific DDD and WDD task formats. Where you are using one of these task formats, follow its exact mandatory requirements and marking instructions. Confirm the permitted project type and submission arrangements with your centre.

## Assessment Overview

The project is worth 80 marks. Version 4.0 allocates them as follows:

| Section | Marks | Main evidence |
| --- | ---: | --- |
| Analysis of the problem | 10 | Problem outline, UML use-case diagram, requirements specification, project plan |
| Design of the solution | 20 | Design based on the requirements |
| Implementation | 30 | Solution matching the completed design; includes ongoing testing |
| Testing the solution | 15 | Persona and test cases, final testing, review of results |
| Evaluation of the solution | 5 | Fitness for purpose, future maintainability, robustness |

For the DDD and WDD formats, the task specifies ten mandatory functional requirements. The requirements differ by format. Use the relevant task pages for their exact wording. This summary is not a substitute for the assessment task.

## Practice Ideas

Use these as starting points for personal practice only. Adapt the complexity and technologies to your chosen project and course requirements.

- Booking system: manage bookings and search availability.
- Environmental monitoring: store readings and display threshold alerts.
- Library system: manage a catalogue, members, and loans.
- Community site: manage posts, comments, and search.

A suitable project should let you demonstrate the relevant SDD, DDD, or WDD skills in the course specification. Avoid adding features that do not help meet your requirements or provide evidence for the assessment.

## Getting Started

1. Read the current course specification and project assessment task.
2. Confirm your project type and task format with your centre.
3. Plan, design, implement, test, and evaluate against the official requirements.
4. Use the marking instructions and required templates as your evidence checklist.
