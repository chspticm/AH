## Course Alignment

Pupils can track their progress with the [course content checklist](./COURSE_CONTENT_CHECKLIST.md).

The course specification has three integrated areas of study:

- **Software design and development (SDD):** computational problem solving, software design, programming, testing, evaluation, and object-oriented or procedural approaches.
- **Database design and development (DDD):** relational database design and SQL.
- **Web design and development (WDD):** web design and implementation using HTML, CSS, and PHP, integrated with database skills.

The course assessment includes a question paper with a mandatory SDD section and a choice of a DDD or WDD section, plus an 80-mark project. The course specification permits SDD using object-oriented or procedural programming integrated with DDD, DDD integrated with SDD or WDD, and WDD integrated with DDD. Follow the current assessment task and centre instructions for task-specific requirements.

| Course area | Related notes in this repository | Coverage |
| --- | --- | --- |
| SDD | Python fundamentals, OOP, data structures, algorithms, practice problems | Partial: useful programming practice, but not a complete match for the course's computational thinking, design, testing/evaluation, and prescribed algorithm/data-structure content |
| DDD | MySQL and SQLite database design, SQL fundamentals, data manipulation, query exercises | Partial: these are practice dialects; use the course specification and assessment task for required SQL, data dictionary, query design, and project evidence |
| WDD | HTML/CSS, PHP, full-stack project notes | Partial: relevant technologies are introduced, but the official HTML forms, PHP processing/sessions, and integrated SQL requirements remain the authority |
| Integration and assessment | Project development guide, checklist, project resources | Supplementary guidance only; not an SQA-issued project or assessment checklist |

This repository contains Markdown notes, Python algorithm examples, and SQL practice scripts for MySQL and SQLite. Some topic-page file lists still describe planned source files or worked solutions that are not included.

## Getting Started

1. Clone this repository
2. Navigate to your chosen language/topic
3. Start with the fundamentals and progress through each section
4. Use the topic notes and examples as prompts for class practice
5. Check course coverage against the official specification and teacher-set work
