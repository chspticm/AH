# Advanced Higher Computing Science Course Content Checklist

Use this checklist to track course content as it is taught and practised. Tick an item when you have covered it in class; revisit it if you are not yet confident applying it. This is a personal progress tracker, not an SQA assessment rubric.

## Course Skills

- [ ] Apply computational thinking to solve complex computing problems.
- [ ] Analyse unfamiliar problems in a computing context.
- [ ] Design, develop, implement, test, and evaluate digital solutions.
- [ ] Use advanced programming skills and explain how a program works.
- [ ] Communicate computing ideas clearly using appropriate terminology and technology.
- [ ] Explain the role and impact of contemporary computing technologies on people and society.

## Software Design and Development (SDD)

### Problem Analysis and Design

- [ ] Analyse a problem and identify its users, requirements, constraints, and expected outcomes.
- [ ] Break a complex problem into smaller components and describe how they interact.
- [ ] Develop a solution design that can be implemented and tested.
- [ ] Read and create UML class diagrams (course specification Appendix 2).

### Programming and Algorithms

- [ ] Use the programming concepts and SQA standardised reference language required by the course.
- [ ] Apply object-oriented programming concepts to design and implement a solution.
- [ ] Apply procedural programming concepts where appropriate to a solution.
- [ ] Select and use suitable data structures for a problem.
- [ ] Explain the structure and operation of a singly linked list, including nodes, data, links, head, and null termination (Appendix 7).
- [ ] Trace and implement linked-list operations, including traversal, insertion, and deletion.
- [ ] Trace, explain, and implement the standard algorithms specified for the course (Appendix 9).
- [ ] Explain how a solution's algorithm and data structures contribute to solving the problem.

### Testing and Evaluation

- [ ] Plan and carry out iterative testing during development (Appendix 15).
- [ ] Use test data and expected results to check program behaviour.
- [ ] Carry out final and end-user testing where appropriate.
- [ ] Review test results and use them to improve a solution.
- [ ] Evaluate a solution for fitness for purpose, efficiency or usability as appropriate, maintainability, and robustness (Appendix 16).

## Database Design and Development (DDD)

- [ ] Identify entities, attributes, keys, and relationships for a relational database.
- [ ] Read and create entity-relationship diagrams (Appendix 3).
- [ ] Create and use a data dictionary (Appendix 4).
- [ ] Design SQL queries from requirements (Appendix 5).
- [ ] Create and manipulate database tables using the SQL operations specified in the course (Appendix 10).
- [ ] Retrieve selected fields from one or more tables using `SELECT`, `FROM`, and `WHERE`.
- [ ] Use the required comparison and logical operators, including combinations of conditions with `AND`, `OR`, and `NOT`.
- [ ] Sort query results using `ORDER BY` and the required sort direction.
- [ ] Use the required aggregate functions: `MAX`, `MIN`, `AVG`, `COUNT`, and `SUM`.
- [ ] Add, change, and remove records using `INSERT`, `UPDATE`, and `DELETE`.
- [ ] Connect to a database from a programming language (Appendix 8).
- [ ] Test database operations and check that the results meet the requirements.

## Web Design and Development (WDD)

- [ ] Design a web solution from requirements and communicate its visual layout and behaviour using wireframes.
- [ ] Model server-side processes using the techniques in the course specification (Appendix 6).
- [ ] Create web pages using the HTML elements required by the course.
- [ ] Create HTML forms using a form's `action` and `method` and the required form controls (Appendix 11).
- [ ] Use form-control attributes such as `name` and `value` to pass data for processing.
- [ ] Process submitted form data using PHP (Appendix 12).
- [ ] Validate form data for presence, length, and range as appropriate.
- [ ] Use PHP sessions to maintain state between pages (Appendix 13).
- [ ] Apply the CSS media-query techniques specified for the course (Appendix 14).
- [ ] Connect the web solution to a database and use the required SQL operations and queries.
- [ ] Test the integrated pages, form processing, validation, and database results.

## Integration and Project Work

The course specification permits projects that integrate SDD, DDD, and WDD in the combinations it describes. The current project assessment task gives specific DDD and WDD task formats; use the task and centre instructions for the project you are completing.

- [ ] Explain how the software, database, and/or web components of a solution exchange data.
- [ ] Analyse the project problem and produce the required analysis evidence.
- [ ] Design all required parts of the solution before implementation.
- [ ] Implement the solution to match the design and maintain evidence of ongoing testing.
- [ ] Test the completed solution against its requirements and report the results.
- [ ] Evaluate the solution against the assessment criteria.
- [ ] Check the exact project type, mandatory requirements, templates, and submission arrangements for my session.

## Assessment Structure

- [ ] Prepare for the question paper's mandatory SDD section.
- [ ] Prepare for the question paper's DDD or WDD section, as applicable to the course assessment.
- [ ] Complete the project assessment task and gather the required evidence.

The project assessment task is worth 80 marks: analysis (10), design (20), implementation (30), testing (15), and evaluation (5). See the [current project assessment task, version 4.0](https://www.sqa.org.uk/sqa/files_ccc/ah-cat-computing-science.pdf) for its detailed marking instructions and task-specific requirements.
