# Practice Problems

## Beginner Level

1. **Number Operations**
   - Calculate sum of digits
   - Check if a number is even or odd
   - Find the largest of three numbers
   - Calculate factorial

2. **String Operations**
   - Reverse a string
   - Count vowels and consonants
   - Check if a string is a palindrome
   - Find duplicate characters

3. **List Operations**
   - Find the maximum and minimum in a list
   - Remove duplicates from a list
   - Reverse a list
   - Sort a list

## Intermediate Level

1. **Data Processing**
   - Filter students by grade
   - Calculate average scores
   - Find outliers in data
   - Group data by category

2. **Pattern Recognition**
   - Print number patterns
   - Generate Fibonacci sequence
   - Find prime numbers
   - Check for anagrams

3. **File Operations**
   - Read and process CSV files
   - Count words in a text file
   - Convert data formats (JSON, CSV)

## Advanced Level

1. **Algorithm Problems**
   - Implement sorting algorithms
   - Solve classic problems (Tower of Hanoi, N-Queens)
   - Implement search algorithms
   - Dynamic programming solutions

2. **Object-Oriented Problems**
   - Design class hierarchies
   - Implement polymorphic behavior
   - Create reusable components
   - Build a mini application

3. **Integration Projects**
   - Student management system
   - Inventory tracking system
   - Personal finance tracker
   - Data analysis tool

## Files in This Section

- `beginner_problems.py` - Beginner level problems and solutions
- `intermediate_problems.py` - Intermediate level problems and solutions
- `advanced_problems.py` - Advanced level problems and solutions
- `project_solutions.py` - Complete project examples

## Assessment Criteria

- Correct problem-solving approach
- Clean and readable code
- Appropriate data structure selection
- Efficient algorithm implementation
- Proper error handling
- Code documentation and comments
