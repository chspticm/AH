# Practice Exercises

## Beginner Level

1. **Basic Queries**
   - Write SELECT queries with WHERE conditions
   - Use ORDER BY and LIMIT
   - Insert and update single records
   - Delete records safely

2. **Simple Joins**
   - Create queries with two-table joins
   - Practice INNER JOIN operations
   - Use LEFT JOIN for reporting

3. **Aggregation Basics**
   - Calculate counts and sums
   - Find maximum and minimum values
   - Group data by category

## Intermediate Level

1. **Complex Queries**
   - Multi-table joins (3+ tables)
   - Subqueries in WHERE and SELECT
   - CASE statements for conditional logic
   - UNION for combining result sets

2. **Advanced Aggregation**
   - GROUP BY with HAVING
   - Multiple aggregate functions
   - Window functions
   - Running totals

3. **Data Modification**
   - Update with JOIN conditions
   - Bulk inserts from other tables
   - Delete with subqueries
   - Transaction handling

## Advanced Level

1. **Performance Optimization**
   - Analyze slow queries
   - Create appropriate indexes
   - Optimize query execution plans
   - Handle large datasets efficiently

2. **Complex Business Logic**
   - Implement stored procedures
   - Create views for reusable queries
   - Implement triggers
   - Handle complex data relationships

3. **Real-world Scenarios**
   - Build reporting queries
   - Create data warehousing solutions
   - Implement audit trails
   - Handle data integration

## Sample Exercises

### Exercise 1: Student Grades System
Create and manage a database for student grades:
- Create tables for students, courses, and grades
- Write queries to find top performers
- Calculate class averages
- Generate student transcripts

### Exercise 2: E-commerce Database
Build an e-commerce database:
- Create tables for products, categories, orders, and customers
- Write queries for product searches
- Calculate sales metrics
- Manage inventory

### Exercise 3: Library Management
Implement a library management system:
- Track books, members, and loans
- Find overdue books
- Calculate late fees
- Generate member reports

## Assessment Criteria

- Correct SQL syntax and execution
- Appropriate query design
- Query optimization
- Data integrity
- Proper handling of edge cases
